# Progression v2: full step flow, externals, editable steps, photos, simple screen

**Status:** plan for review. Nothing built yet.

## 1. What's wrong with the steps today

- **Two lists per floor** (Pre-slab 56 + Post-slab 56). They mix structure checks, finishes and some **building-level external work**.
  - "External wall plaster" and "External façade works" sit inside every floor.
  - On site, external plaster, texture and painting run **from the top down on scaffolding, per building face**, not floor by floor.
- **Waterproofing is thin and hidden.** Three steps sit inside "Waterproofing and wet-area preparation". There's no sunken-slab treatment before filling, and nothing for balconies, terrace, water tank, external walls or lift pit / basement.
- **Missing common steps:**
  - sunken-area filling;
  - gypsum / POP false ceiling;
  - MS grills and railings;
  - DB dressing and earthing;
  - fire sprinklers and detectors;
  - low-voltage cabling (CCTV, intercom, data);
  - gas line;
  - concrete cube test results;
  - second paint coat as its own step.
- **Every step weighs the same.** "Apply release agent" counts as much as "Slab concreting". A floor that's done all its small checks looks further ahead than it is.
- **No photos, and steps can't be added or removed per project.**
- **The screen is busy.** Schedules, evidence, verification and phases are all visible at once, which is hard for a site supervisor using one hand.

## 2. New structure: three lists

| List | Applies to | What it covers |
|---|---|---|
| **Inside (per floor)** | every floor | Structure → walls → services → plaster → waterproofing → flooring → doors & windows → paint → fixtures → handover |
| **Outside (per building)** | each tower / block | Scaffolding, external plaster or texture, external waterproofing, façade, external paint, terrace, external plumbing, lift |
| **Site works (per project)** | the whole site | Compound wall, drainage, STP, water, power, roads, landscaping, statutory handover |

The structure part of "Inside" keeps the method-specific checklists (Conventional, Mivan, Hybrid). Everything after the slab follows the same flow, with the method changing only the wall and plaster steps.

## 3. Step lists (Conventional; Mivan and Hybrid swap the marked phases)

Each phase has a **weight**: its share of the effort on that list. A floor's % adds up each phase's progress × its weight. Inside a phase, each step counts equally.

### 3.3 Site works, per project (100%)

1. **Utilities, 30%:** external drainage and manholes; STP / septic tank; underground water tank; rainwater harvesting pits; power substation / transformer and DG set.
2. **Hardscape, 30%:** compound wall and gate; internal roads and kerbs; paving and parking marking.
3. **Softscape and amenities, 20%:** landscaping and plantation; amenities (clubhouse, play area, if any); site lighting.
4. **Statutory and handover, 20%:** fire NOC; lift licences; Occupancy Certificate; society / owner handover.

## 4. How the % works (revised)

1. **A step** is 0% when not started, 0% when started (it's shown as "in progress" but earns no credit), and 100% when done. That keeps the meaning simple and photo-backed.
2. **A phase's %** is its steps done ÷ its steps (skipped / N/A steps are left out).
3. **A list's %** adds up each phase's % × the phase weight (weights add to 100; phases with no steps share their weight with the rest).
4. **Inside, per building:** the average of its floors (unstarted floors count as 0%, as today).
5. **Project %:**
   - **Inside 70% · Outside 20% · Site works 10%**, each part being the average across its buildings or the project.
   - The split is editable per project. An interior-only project can set Outside and Site to 0, and the rest renormalises.
6. **Planned %, variance and status** use the same weights, so "behind plan" means the same everywhere: dashboard, S-curve, report.
7. **Zones** still replace a floor's Inside % when a floor has zones (unchanged).

## 5. Adding, hiding and editing steps (per project)

- **Who:** BuildView staff and the Client Admin.
- **Edit steps** button on any list: rename a step, move it up or down, mark it optional, add a step to a phase, or hide a step.
  - Changes apply to **every floor** (or building) using that list on this project.
  - The first edit gives the project its own copy of the list. Other projects aren't affected.
- **Hide vs. delete:**
  - A step nobody has started is removed.
  - A step with recorded work is **hidden**: it stops counting toward %, and its history and photos stay.
- **Per floor:** any step can be set to **N/A** on one floor, for example "Gas line" on a floor without kitchens.
- **Phase weights** are editable in the same screen, with a live check that they add up to 100.
- The edit is written to the activity log, and existing progress carries over (the same step-key carry-over used for method changes).

## 6. Photos on Start and Done

- Tap **Start** or **Done** and a small sheet appears with a **big camera button** ("Take photo"), plus "Choose from gallery" and "Skip".
- **Upload:** the photo is shrunk on the phone (about 1600 px, ~300 KB) and uploads in the background, so the step updates instantly. If the network drops, it retries.
- **Project setting:** "Photo required to finish a step". Off by default; it can be switched on per project or per phase (e.g. waterproofing and ponding tests).
- **Where photos show:**
  - on the step: a thumbnail before and after; tap for full screen and swipe between photos;
  - in verification, next to the 360 scan;
  - in the PDF report, where each changed step gets "before / after" thumbnails.
- **Stored** privately (signed links only), with who took it, when and from which step. Location only if the phone allows it.

## 7. The simple screen ("as easy as WhatsApp")

Mobile first; on desktop the same layout sits in a centred column.

```
┌───────────────────────────────┐
│ ◀  Tower A · Floor 3      63% │  ← one header: where you are + floor %
│ [ Inside ] [ Outside ] [ Site]│  ← three big tabs
├───────────────────────────────┤
│ NEXT UP                       │
│ ● Sunken slab waterproofing   │
│   [ 📷  Start ]               │  ← one big green button
├───────────────────────────────┤
│ ✓ Structure            100% ▸ │
│ ✓ Walls                100% ▸ │
│ ◐ Services              70% ▾ │  ← tap to open a phase
│   ✓ Conduits and boxes   📷2  │
│   ◐ Water supply lines        │
│     Started 2 h ago · Ravi    │
│     [ 📷  Done ]              │
│   ○ Soil and waste lines      │
│     [ Start ]                 │
│ ○ Plaster                 0% ▸│
└───────────────────────────────┘
```

**Rules:**
- **One action per step:** the next step shows **Start**, a step in progress shows **Done**, a finished step shows a ✓ with photo count.
- **Big touch targets:** buttons ≥ 48 px tall and full width on phones; text 16 px; icons always come with a word.
- **"Next up" card:** the next sensible step, so most days are one tap.
- **Phases stay closed** except the current one, which opens on its own. Each shows a progress bar and %.
- **Long-press or ⋯ menu on a step:** Undo, Add note, Change date, Mark N/A, Verify (verifiers), View photos.
- **Floor switch:** tap the header for a list of floors with their %, like a chat list. Search by name.
- **Advanced views stay one tap away, not on the main screen:** planned dates, S-curve, zones and verification, under **More**.
- **Feedback:** the button shows a spinner while saving, and a ✓ toast says what changed ("Done: Sunken slab waterproofing · photo uploading").
- **Built for site use:** works in direct sunlight (high contrast, no light-grey text), with one hand (key buttons at the bottom on phones), and on slow networks.
- **Language (option, later):** English / हिंदी / मराठी labels for site staff.

## 8. What stays the same

Construction methods, zones and trades, verification, evidence scans, planned dates, the S-curve, the PDF report, notifications and link analytics all keep working. They read the new lists and weights.
