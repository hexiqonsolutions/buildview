# Activities Page Overrides

> **PROJECT:** BuildView CRM  
> Module 7 — Activity timeline (calls, meetings, emails, tasks, notes).

---

## Intent

Unified vertical timeline on OLED black with orange accents. Filter chips by type. Manual logging for CALL / MEETING / TASK / NOTE; EMAIL entries appear from the Email module. Dense list, Lucide icons, empty state with Log activity CTA.

---

## Layout

1. Hero strip + Log activity  
2. Type filters (All / Call / Meeting / Email / Task / Note)  
3. Timeline rail with icon nodes  
4. Create/Edit dialog (type, lead, title, body, occurred at)
