# Documents Page Overrides

> **PROJECT:** BuildView CRM  
> Module 8 — Document library (PDF, proposal, quotation, contract, invoice, image).

---

## Intent

File library on OLED black with orange accents. Filter by document type. Upload linked to optional lead. Dense table/list with size, uploader, dates. Empty state with Upload CTA. Brand tokens from MASTER.md win over ui-ux-pro-max blue defaults.

---

## Layout

1. Hero strip + Upload document  
2. Type filters (All / PDF / Proposal / Quotation / Contract / Invoice / Image / Other)  
3. Search + document rows (name, type, lead, size, uploaded by, date)  
4. Upload/Edit dialog (file, type, name, lead)  
5. Download + soft-delete actions
